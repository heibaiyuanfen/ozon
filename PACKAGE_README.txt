Ozon 广告与销量分析 v0.15.3

1. 双击“OzonAnalytics.exe”启动。
2. 数据、API 设置和运行日志保存在同目录的 data 文件夹中。
3. 当前便携包已复制打包时的本地数据库，可直接延续已有数据。
4. API 密钥采用 Windows DPAPI 加密，只能由当前 Windows 用户解密。
5. 如需把软件发给他人，请只发送 EXE，或先删除 data 文件夹，避免携带店铺数据。
6. Windows Defender 首次检查单文件 EXE 时可能需要等待数秒。
7. “飞书同步”支持商品成本多维表格双向同步、周报写表和群消息发送。
8. 如需软件关闭后仍自动发送，请在“飞书同步”中点击“安装后台计划任务”。
9. “库存管理”先展示全部商品；双击 SKU 可打开全部集群明细，修改计划补货并导出 Excel。
10. “约仓计划”自动读取库存页保存的补货量；双击集群或点击“创建 Ozon 约仓”打开分步向导。
11. 向导支持直送/越库发货点、草稿校验、目的仓、时段和正式供应申请。远程写操作都会二次确认且只发送一次。
12. AI 页面不会调用 Ozon 广告接口，只读取“数据中心 → 快速同步广告”保存的本地缓存。
13. 单商品 AI 优先使用本地精确 SKU 明细；没有时只匹配名称明确含 SKU/货号的专属活动，并标注为活动级推算。
14. 所有下拉框都可输入并即时展开模糊匹配；输入 GJYB 可列出全部包含 GJYB 的选项。
15. 月度盈亏表可按货号/SKU 搜索并填写成本；成本窗口支持按 GJYB001 等货号系列批量同步单件成本与头程。
16. 左侧店铺选择器可新增本土店或跨境店；每店的数据库、API 凭证、SKU、广告、财务和成本完全隔离。
17. “产品成本”以人民币保存采购成本和头程，并按每个店铺自己的 RUB/CNY 汇率实时换算月度盈亏。
18. “跨境店利润”只列日期范围内有出单的 SKU；保存未出单商品的历史成本，但不会用无销量商品拉长报表。
19. 跨境利润采用实时预估口径：Seller Analytics 下单销售额 - 历史已结算佣金/收单费率 - 采购 - 预估运费；全店广告只在期间/周汇总扣除，不伪造单品分摊。
20. 本土店与跨境店采用独立数据库和独立 API；本土店数据不会再作为跨境预览数据。
21. 跨境利润页可直接维护 1 CNY=X RUB，销售、广告和平台净额统一换算为人民币后计算。
22. 发货点首次联网查询后按店铺缓存；普通搜索直接读本地，只有点击“联网刷新”才再次请求 Ozon。
23. 越库约仓会把 Ozon 返回的未指定仓库枚举修正为 CROSS_DOCK，避免 warehouse_type=0 的 HTTP 400。
24. “API 配置中心”的编辑区固定显示，可直接新增、命名、切换和修改店铺类型。
25. 修改本土/跨境类型会启用新的独立数据库；旧数据库保留，防止两类数据混用。
26. “跨境上品”可打开配套 RFBS 上品工具；启动前会自动选中当前跨境 Seller API，本土店下禁止启动。
27. 上品产品台账.xlsx 继续按台账店铺同步采购成本、重量和包装尺寸。
28. 跨境利润页从本地 Finance 缓存区分 FBP、FBS/realFBS、WHD 履约订单；销量和销售额仍以 Seller Analytics 为准。
29. Finance 已结算净额仅作为对账列，不再用未签收订单对应为空的结算收入计算当天利润；产品行和周报均展示实时公式。

如需重新打包：右键 build_exe.ps1，选择“使用 PowerShell 运行”。
