# 图二 RETS 运费公式设置

采用俄罗斯/莫斯科六档，费用本身是人民币。

1. M2 写“汇率：1 CNY = RUB”，N2 填有效正数，如 12。
2. E3:F8 依次填写：3.37 / 28.1；17.97 / 28.1；24.71 / 28.1；25.83 / 19.1；40.44 / 28.1；69.64 / 25.8。不要混用其他线路的公式。
3. 图二 E15 为实重 kg，F15 为人民币售价，Q15/R15/S15 为长宽高 cm；若实际列不同，请替换尺寸引用。
4. 将“图二_K15公式.txt”整行粘贴到 K15，然后向下填充。已有 LET/IFS 的表格环境可用该公式。
5. 卢布档位 1500 / 7000 / 250000；人民币分界 = 卢布 ÷ N2。可将 1500/$N$2、7000/$N$2、250000/$N$2 分别作为显示公式。

0.5/2/5/30kg 含端点，重叠端点先选尺寸合规的小件渠道。金额最后保留两位；实重不向上进位。缺少尺寸、超尺寸、超重或货值超限会提示，不输出虚假 0 运费。真实跨档的跳价保留。此表未评价带电/禁运品资质。

随附测算表使用更易核查的中间步骤：先换算货值 RUB，再选择合规档位，最后按票费+实重×重量费计算运费；黄色单元格可改。

表头和档位文字也要同步：C2 改为“货值（RUB）”，C3/C6 为“1～1500”，C4/C7 为“>1500～7000”，C5/C8 为“>7000～250000”。D3、D4、D5 分别为“≤0.5kg / ≤2kg / ≤5kg”；D6、D7、D8 分别为“0.5～30kg / 2～30kg / 5～30kg”。重叠端点先选择尺寸合规的小件档。

示例：N2=12 时，1500/7000/250000 RUB 分别对应 125 / 583.333333 / 20833.333333 CNY。参考测算文件中的汇率输入位于 J2；图二粘贴公式使用 N2。
