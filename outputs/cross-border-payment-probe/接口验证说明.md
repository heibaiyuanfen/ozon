# 跨境店付款汇率接口验证

2026-10-20，只读查询跨境店“非凡智汇／跨境一店”。

## 已验证：余额报告

POST https://api-seller.ozon.ru/v1/finance/balance

请求头使用店铺已有 Client-Id、Api-Key，不在报告记录密钥。

```json
{"date_from":"2026-09-01","date_to":"2026-09-30"}
```

HTTP 200。关键字段：

```json
{
  "total": {
    "opening_balance": {"value":54899.23,"currency_code":"RUB"},
    "closing_balance": {"value":115321.79,"currency_code":"RUB"},
    "accrued": {"value":214691.56,"currency_code":"RUB"},
    "payments": [{"value":-154269,"currency_code":"RUB"}]
  }
}
```

数据与用户提供的9月余额历史截图一致（截图取整）。本次响应是期间汇总，不包含逐笔付款日期和付款单号。

## 尚未验证：人民币付款列表

下一步需用户提供两个页面的脱敏网络请求（请求URL、方法、请求体和响应，去除Cookie、Authorization等认证信息），或连接已登录浏览器。

## 仅用于对账的计算

API返回的9月卢布付款总额154269，用户付款截图9月已付款人民币12916.15。
若两份数据属于同一店铺、覆盖同一批已完成付款，期间有效结算汇率 = 154269 / 12916.15，约11.9439 RUB/CNY。
人民币金额来源为截图，并非API；尚未完成两接口自动关联。
逐笔关联优先使用付款ID、单号、结算批次；仅日期相同不能保证为同一付款。
排除待付款和失败记录；跨月付款需核对实际付款日期。汇总汇率使用卢布合计/人民币合计，不平均逐笔汇率。
