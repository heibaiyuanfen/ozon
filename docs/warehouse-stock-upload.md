# 跨境仓库库存修改

1. 打开跨境店「商品中心」，点击「读取仓库、商品及实时库存」。
2. 选择目标仓，筛选并全选需要修改的商品。
3. 填写「目标仓覆盖库存」与「原仓调整后库存」，点击「应用到已选商品」；也可逐项填写。
4. 点击列表上方固定操作栏「① 核对修改并生成预览」。多个原仓时先逐项选择原仓；原仓与目标仓不能相同。
5. 核对预览中的原仓、目标仓及修改前后数量，再点击「② 确认上传库存修改」。只有这一步及确认后的操作才写入平台。

目标仓写入并回读成功后才修改原仓。原仓可保留指定数量，不强制为0；目标库存是覆盖，不是累加。其他仓、FBP仓、预留库存及已有订单不迁移。

无效SKU（0、负数、非数字）跳过读取并禁止提交，不阻断其他商品。批量请求被平台400拒绝时拆成逐商品读取；认证、限频和网络等错误停止读取，避免连续请求。已成功读取的商品可继续预览和提交。

库存操作不是平台原子事务。结果未知或部分成功时先核对Ozon后台和历史操作记录，不自动重复上传。

## 执行进度与避免重复提交
- 提交期间每1.5秒读取本地持久执行记录，展示总件数、成功、失败、部分完成、待核对、跳过、处理中、待处理。
- 商品列表及本批结果同时显示逐项状态、最近平台回读的原仓/目标仓库存与时间。填写值不等于实际回读值，无法确认时保留“待核对”。
- 结果支持按状态筛选。历史记录点击“查看逐项结果”可查看已有回执；旧批次未保存回读值时显示未知，不用目标填写值补造。
- 选择OGL等目标仓后，可勾选“排除目标仓已有库存（含预留）”，隐藏并从选择中剔除已有库存商品；也可只点击“从已选中去除目标仓已有库存”。
- 勾选排除后，服务器在预览和执行前再次检查目标仓可售/预留/在仓数量，有库存则跳过整件，原仓不改。未勾选时仍按用户明确的覆盖数量操作。
