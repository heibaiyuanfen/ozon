# Seerfar 浏览器辅助扩展（试验版）

此扩展只在 Ozon ERP 打开带一次性 `ozon-erp-capture` 标记的 Ozon 商品页时工作。它读取页面上**可见且可被网页 DOM 访问**的 Seerfar 面板文字，把当前 SKU 的字段回传到本机 `127.0.0.1` 临时端口；不会访问 Seerfar 账号、Cookie 或扩展私有存储，也不会向外部服务器上传。

手动安装：在装有 Seerfar 的 Chrome/Edge 中打开扩展管理页，启用开发者模式，选择“加载已解压的扩展程序”，选择本目录。安装和浏览器权限须由用户自己确认。然后先登录 Ozon 和 Seerfar，再在 ERP 的“竞品店铺拆解”导入 Excel，对商品点击“Seerfar 补全”。

扩展源码更新后，已安装的用户需要在扩展管理页点击此扩展的“重新加载”，再重新点击“Seerfar 补全”；仅更新 ERP 启动器不会自动更新浏览器扩展。面板加载较慢时，扩展会在一次性接收窗口内每 2 秒重试，最多等待 90 秒。

诊断：从 ERP 点击“Seerfar 补全”打开的商品页右上角会出现 `Ozon ERP` 采集状态条。没有状态条，说明浏览器扩展没有识别到一次性采集链接（检查地址栏末尾是否有 `#ozon-erp-capture=...`、是否在安装了本扩展的同一个 Chrome 配置文件中打开）。出现“等待面板”说明链接已识别但尚未读到可访问的 Seerfar 面板；SKU/售价提示对应字段解析问题；“本机回填失败”会显示接收端错误。普通手动打开的商品页不会显示状态条。

若页面能看到 Seerfar 面板但状态最终提示售价标签不在“可读取的页面 DOM”中，说明只是视觉上可见，不能断言同页脚本能读取；面板可能由其他扩展放在隔离 iframe 或封闭 Shadow DOM。此时不要关闭 Chrome 安全设置、尝试访问其他扩展的私有数据，或者把缺失字段记为零。可改用 Seerfar 自有导出文件补全，或等待经平台许可的接口。

限制：若 Seerfar 面板位于跨源 iframe、closed Shadow DOM，或者字段标签与当前中文标签不同，Chrome 的隔离机制会阻止此扩展读取。此时 ERP 保留 Excel 原值，补全不会显示成功；不应把缺失值记作零。当前实现是试验版，需在实际 Seerfar 页面上验收字段解析。
